# IoT Research | Thesis Template

##  English 
In this repository, there is the official LaTeX Thesis template of the IoT Research Lab.

You can work on it with any LaTeX IDE (such as [TexStudio](https://www.texstudio.org/)) or on [Overleaf](https://www.overleaf.com/project).

## Italian 
In questa repository, trovi il template tesi LaTeX ufficiale del IoT Research Lab.

Puoi lavorarci con un qualsiasi IDE per LaTeX (come [TexStudio](https://www.texstudio.org/)) oppure su [Overleaf](https://www.overleaf.com/project).
